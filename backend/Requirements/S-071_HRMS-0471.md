## 2. WHY THIS EXISTS

How effective is Thunder? What percentage of candidates does Thunder qualify without human intervention? What is Thunder's average time-to-qualification vs human baseline? What is the escalation rate? These metrics tell leadership whether to expand Thunder's autonomy or pull back. Without them, the investment in Thunder is unmeasurable.

This story provides the KPI dashboard for Thunder's autonomous recruiting performance.

## 3. WHAT YOU ARE BUILDING

Build Thunder Performance Analytics dashboard at /recruiter/thunder-analytics. Metrics: qualification rate, escalation rate, ghosting rate, avg time-to-qualify, messages per candidate, human intervention rate, and trend charts over selectable time periods.

## 5. STEP-BY-STEP EXECUTION

▶  Follow these steps in exact order. If a step is unclear, ask the lead BA — never assume.

## Step 1: Build GET /api/analytics/thunder endpoint

- Auth: recruiter or admin auth. Filter by tenant_id.

- Params: ?date_from={ISO}&date_to={ISO} (default: last 30 days)

- Returns: { summary: { qualification_rate, escalation_rate, ghosting_rate, avg_days_to_qualify, avg_messages_per_candidate, human_intervention_rate }, trends: [{ date, qualifications, escalations, ghostings, new_candidates }], top_risk_candidates: [top 5 by drop risk], agent_actions_breakdown: { thunder_actions, human_actions, thunder_pct } }

- qualification_rate = COUNT(reached QUALIFIED state) / COUNT(entered QUALIFYING state) * 100

- escalation_rate = COUNT(ESCALATION events) / COUNT(active conversations) * 100

- ghosting_rate = COUNT(candidate_ghosting_status records) / COUNT(active conversations) * 100

- human_intervention_rate = human_actions / (thunder_actions + human_actions) * 100

## Step 2: Build Thunder Analytics Dashboard page

- Route: /recruiter/thunder-analytics

- Date range picker at top (Last 7 days / Last 30 days / Last 90 days / Custom)

- Row 1 — KPI cards: [Qualification Rate: X%] [Escalation Rate: X%] [Ghosting Rate: X%] [Human Intervention: X%]

- Row 2 — Trend line chart: daily qualifications vs escalations vs ghostings over selected period

- Row 3 — Two metrics: [Avg Days to Qualify: X] [Avg Messages per Candidate: X]

- Row 4 — Thunder vs Human actions donut chart: Thunder X% vs Human Y%

- Row 5 — Top 5 risk candidates table (from drop risk scores)
