## Why — Business Rationale

- For adhoc demands, bench check must happen in minutes. This story builds the instant match variant: returns ranked bench candidates within 10 seconds.

## What — Scope

- InstantBenchMatcher: fast bench search returning top 5 ranked candidates within 10 seconds. Considers skill match, delivery engine, bench duration, Core eligibility.

## Before — Prerequisites

- HRMS-0503 bench pool. HRMS-0509 matching. HRMS-0513 Core eligibility.

## Implementation Steps

## Step 1: Build InstantBenchMatcher

- InstantBenchMatcher.match(demand_id): query employees WHERE status=BENCH AND delivery_engine matches. Skill match % (60%), bench_duration_days (20%), core_eligible (20%). Returns top 5. Stores in adhoc_bench_matches. Runtime < 10 seconds.

## Step 2: Build instant match notification

- Notify RM via portal + WhatsApp with top match. If zero matches: sourcing recommendation notification.
