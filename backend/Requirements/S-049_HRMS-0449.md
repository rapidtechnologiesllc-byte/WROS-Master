## 2. WHY THIS EXISTS

Once a matching interview slot is found, all parties must be confirmed immediately: the candidate (via WhatsApp/email with time in their timezone), the interviewer (via email with calendar invite), and the recruiting team. A confirmation that arrives minutes after scheduling is professional and reduces no-shows significantly.

## 3. WHAT YOU ARE BUILDING

Build: (1) Send candidate interview confirmation via Thunder (WhatsApp + Email). (2) Send interviewer calendar invite via Outlook. (3) Store confirmation events. (4) Generate ICS file for candidate's calendar. All times shown in each party's local timezone.

## 5. STEP-BY-STEP EXECUTION

▶  Follow these steps in exact order. If a step is unclear, ask the lead BA — never assume.

## Step 1: Build sendCandidateConfirmation() function

- Load interview record: scheduled_at_utc, duration_minutes, candidate_timezone, interviewer name (from user record), meeting_link

- Convert scheduled_at_utc to candidate_local_time using candidate_timezone

- Generate Thunder's confirmation message via INTERVIEW_CONFIRMATION prompt:

- 'Great news, [name]! Your interview with [Interviewer Name] at BlitzenX is confirmed. Date: [day, date]. Time: [time in candidate timezone]. Duration: [X] minutes. Format: [video call link OR phone]. We are excited to learn more about your background!'

- Include: meeting link (if video), phone number (if phone interview), any prep tips

- Send via BOTH WhatsApp AND Email (confirmation is too important for single channel)

- Email includes ICS attachment so candidate can add to their calendar (Step 2)

## Step 2: Generate ICS calendar file for candidate

- Build .ics file: BEGIN:VCALENDAR, VEVENT with DTSTART (UTC), DTEND (UTC), SUMMARY: 'Interview with BlitzenX', DESCRIPTION: 'Interview with [Interviewer Name]', LOCATION: meeting_link or phone number, ORGANIZER: thunder@blitzenx.com

- Attach to confirmation email as interview_confirmation.ics

- This allows candidate to add directly to iOS/Google/Outlook calendar with one tap

## Step 3: Create Outlook calendar event for interviewer

- POST to Microsoft Graph: POST /users/{interviewer_id}/events

- Event: SUMMARY='Interview: [Candidate Name] — [Job Title]', start=scheduled_at_utc converted to interviewer_timezone, end=start + duration, body=candidate profile summary + resume link, attendees=[interviewer email, optionally recruiter email]

- On success: UPDATE interviews.calendar_event_id with the created event ID (for future updates/cancellations)

- On API failure: log CALENDAR_INVITE_FAILED. Send email to interviewer instead as fallback. Notify recruiter.

## Step 4: Update interview status and publish event

- UPDATE interviews SET status='CONFIRMED', confirmed_at=NOW()

- INSERT conversation_events: INTERVIEW_CONFIRMED { candidate_id, interview_id, scheduled_at_utc }

- Publish event: interview.confirmed { candidate_id, interview_id } → triggers HRMS-0450 Reminder Engine

- Update candidate_conversations state to INTERVIEW_SCHEDULED via transitionState()

## 6B. BUSINESS RULES

▶  Every rule is non-negotiable. If in doubt, escalate to lead BA — never silently skip a rule.

## BR-01: Confirmation Sent on Both WhatsApp AND Email

Interview confirmation is too important to risk on a single channel. Send via both WhatsApp and email regardless of the candidate's preferred channel. This is the one exception to channel preference logic.

↳ Triggered by field: Send via BOTH channels — not just preferred

## BR-02: Candidate Timezone in All Candidate-Facing Times

Every time shown to the candidate must be in their timezone. Every time shown to the interviewer must be in the interviewer's timezone. Never show UTC to either party. Never show the interviewer's timezone to the candidate (causes confusion).

↳ Triggered by field: timezone display rules

## BR-03: Calendar Invite Must Be Created for Interviewer

The interviewer must receive an Outlook calendar event. Email-only notification is insufficient — interviews get missed when they are not in the calendar. Outlook event creation is mandatory, not optional.

↳ Triggered by field: calendar_event_id on interview record
