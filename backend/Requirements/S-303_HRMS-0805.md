## Why — Business Rationale

- A project with an approaching start date and an unfilled role is a staffing emergency waiting to happen — the earlier that gap is visible, the more runway there is to fill it through the standard bench-first-then-source pipeline instead of scrambling at the last minute.

## What — Scope

- A view of every open (unassigned) role across all active projects, with an alert that fires as the project's start date approaches while the gap remains, triggering an immediate bench search.

## Before — Prerequisites

- S-301 must be live — a gap is defined as a project role with no corresponding assignment.

## Implementation Steps

## Step 1: Build the unfilled roles view

- Cross-references project role requirements (from the originating demand, per S-239) against actual assignments (S-301) — any role without a matching assignment is a gap.

## Step 2: Build the approaching-start alert

- Days-until-start decreasing while a gap remains triggers escalating urgency, culminating in an immediate bench search trigger 7 days before start.

## Step 3: Wire the bench search trigger

- Reuses HRMS-1102's existing demand-gap detection rather than building a parallel mechanism — this view surfaces the gap for human visibility, HRMS-1102 is what actually initiates sourcing.

## Business Rules

BR: BR-0805-01 — This view triggers HRMS-1102's existing sourcing mechanism, it doesn't duplicate it

- Avoids building a second, parallel demand-gap detection system when HRMS-1102 already does exactly this job — this story is the project-delivery-side visibility into gaps HRMS-1102 is already positioned to act on.

- Field: The 7-day urgent trigger publishes to the same sourcing_alerts mechanism HRMS-1102 already consumes

## Acceptance Criteria

- AC-1: A project role with no matching assignment appears in this view as a gap.

- AC-2: A gap within 7 days of project start triggers HRMS-1102's sourcing mechanism rather than a separate, duplicate one.

- AC-3: Gap status correctly reflects OPEN/URGENT/OVERDUE based on days until start.
