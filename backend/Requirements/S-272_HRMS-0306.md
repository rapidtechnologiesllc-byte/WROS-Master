## Why — Business Rationale

- Gap analysis is the engine room of workforce planning: it compares what BlitzenX needs (demand) against what it has (bench + in-flight hiring) and produces the net gap — how many people of what skill, for which delivery engine, must be sourced externally. Without this, every hiring decision is made without knowing the full picture.

## What — Scope

- Build the gap analysis engine: supply (bench + in-flight hires + HTD pipeline) minus demand (approved plan + active demands + pipeline) = net gap per role per delivery engine. Produce actionable gap report.

## Before — Prerequisites

- HRMS-0303 demand plans. HRMS-0503 bench pool. HRMS-0513 Core eligibility (to know which bench employees are Core-eligible). HTD pipeline data from EPIC-P5.

## Implementation Steps

## Step 1: Build GapAnalysisEngine service

- GapAnalysisEngine.analyze(bu_id, horizon_days=90): Supply side: (1) BENCH employees with matching skills (from HRMS-0503). (2) In-flight external hires (candidates in OFFER_READY or OFFER_ACCEPTED stage). (3) HTD pipeline employees expected to complete within horizon. Demand side: (1) workforce_demand_plan_items (approved plans). (2) Open demands. (3) PIPELINE demands weighted by probability.

- Net gap per role = demand_total - supply_total. Positive = shortage (must hire). Zero/negative = covered (may have surplus).

- Delivery engine split: calculate separately for SPECIALITY and CORE — bench employees cannot be cross-applied without going through Core Eligibility Gate (HRMS-0513).

## Step 2: Build GET /api/workforce-planning/gap-analysis

- Returns: { gap_summary: { total_gap_speciality: N, total_gap_core: N }, by_role: [{ role_type, delivery_engine, demand: N, supply_bench: N, supply_in_flight: N, supply_htd: N, net_gap: N, urgency }] }

- urgency: CRITICAL (net_gap > 0 and target_start_date < 30 days), HIGH (31-60 days), NORMAL (61-90 days).

## Step 3: Build Gap Analysis Dashboard

- Route: /admin/workforce-planning/gap-analysis

- Summary: Total supply, total demand, net gap. Color-coded: red gap, green surplus.

- Drill-down per role: supply breakdown (bench/in-flight/HTD) vs demand sources (plan/active/pipeline).

- Export to PDF: gap analysis report for weekly staffing review.

## Business Rules

## BR: SPECIALITY and CORE Gaps Calculated Independently

- An employee on bench in SPECIALITY cannot fill a CORE gap without passing the Core Eligibility Gate (HRMS-0513). The gap analysis reflects this: SPECIALITY bench does not reduce CORE gap. This prevents the system from showing a false 'covered' status for Core roles when supply only exists in Speciality.

- Field: No cross-engine supply application without eligibility gate

## BR: HTD Pipeline Supply Only Counted If On Track

- HTD candidates in training are counted as future supply only if their current phase gate has been passed on schedule. Candidates in GATE_FAILED or EXTENDED status are excluded from supply forecast. This prevents over-counting supply from struggling HTD cohorts.

- Field: HTD supply = on-track candidates only
