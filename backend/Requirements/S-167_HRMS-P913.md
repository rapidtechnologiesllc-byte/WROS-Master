## 2. WHY THIS EXISTS

When evaluating whether a candidate's salary expectation is reasonable, it helps to know the market rate for their skill set and location. This story adds a market benchmark reference (manually curated by BA, not live API integration) to give context to compensation decisions.

## 3. WHAT YOU ARE BUILDING

Build a market_salary_benchmarks table (BA-curated reference data) and display benchmark comparison on candidate profile near compensation score.

## 4. BEFORE YOU START

▶  Do NOT write a single line of code until every item below is confirmed complete.

## 5. STEP-BY-STEP EXECUTION

▶  Follow these steps in exact order. If a step is unclear, ask the lead BA — never assume.

## Step 1: Build market_salary_benchmarks table

- id, tenant_id, skill_canonical, experience_band ENUM('0-2','3-5','6-10','10+'), region, p25_usd, p50_usd, p75_usd, updated_at, updated_by. BA manually populates and updates quarterly.

## Step 2: Build benchmark lookup and display

- getBenchmark(skill_canonical, experience_years, region) → nearest matching benchmark row. Display on candidate profile: 'Market range for Guidewire PolicyCenter (5-7 yrs, US): $95k-$120k. Candidate expects: $110k (within range).'
