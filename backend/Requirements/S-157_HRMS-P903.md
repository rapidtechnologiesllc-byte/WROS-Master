## 2. WHY THIS EXISTS

Most recruiters cannot write raw boolean syntax correctly. A visual query builder — similar to HRMS-P406 LinkedIn query builder but for the internal database — makes powerful search accessible without requiring boolean syntax knowledge.

## 3. WHAT YOU ARE BUILDING

Build a visual drag-and-drop / tag-based query builder UI that generates boolean queries, plus an advanced mode for power users to type raw boolean strings directly.

## 4. BEFORE YOU START

▶  Do NOT write a single line of code until every item below is confirmed complete.

- HRMS-P901/P902 backend ready.

## 5. STEP-BY-STEP EXECUTION

▶  Follow these steps in exact order. If a step is unclear, ask the lead BA — never assume.

## Step 1: Build visual builder mode

- Three sections like HRMS-P406: MUST HAVE (AND), NICE TO HAVE (OR), EXCLUDE (NOT). Tag inputs with autocomplete from existing candidate skills/titles/companies.

- Generated query shown live below builder.

## Step 2: Build advanced raw query mode

- Toggle to switch to a text input where power users type boolean syntax directly.

- Syntax highlighting for AND/OR/NOT/parentheses. Real-time validation with error underline.

## Step 3: Build results display

- Paginated results with matched terms highlighted in resume snippet. Sort by relevance or recency. Filters: status, location, experience range applied alongside boolean query.
