## 2. WHY THIS EXISTS

The Intervention Queue shows candidates needing immediate action. The Risk Dashboard provides a broader view — all active candidates with their risk levels visualized, trend lines, and filtering by risk dimension. A recruiter using the Risk Dashboard can spot systemic issues: 'Why do all Guidewire candidates have high abandonment scores?' or 'Why is the interview stage showing high drop risk this week?'

## 3. WHAT YOU ARE BUILDING

Build a Risk Dashboard page at /recruiter/risk-dashboard. Shows: (1) Risk heatmap grid — all active candidates color-coded by drop_risk_score. (2) Sentiment trend chart — aggregate sentiment over last 14 days. (3) Stage risk breakdown — average risk by pipeline stage. (4) Filters by risk level, stage, and score dimension.

## 5. STEP-BY-STEP EXECUTION

▶  Follow these steps in exact order. If a step is unclear, ask the lead BA — never assume.

## Step 1: Build GET /api/risk/dashboard endpoint

- Auth: recruiter auth. Filter all by tenant_id.

- Returns: { risk_summary: { critical_count, high_count, medium_count, low_count }, candidates_at_risk: [{ candidate_id, name, drop_risk_score, risk_level, stage, top_risk_signal }] sorted by drop_risk_score DESC, sentiment_trend: [{ date, avg_positive_pct, avg_negative_pct }] for last 14 days, stage_risk_breakdown: [{ stage, avg_risk_score, candidate_count }] }

- candidates_at_risk: only includes candidates with drop_risk_score >= 40 (MEDIUM and above)

## Step 2: Build Risk Dashboard page

- Route: /recruiter/risk-dashboard

- Top row — 4 summary cards: [Critical: X] [High: X] [Medium: X] [Low: X] with trend arrow vs last week

- Middle — Candidates at Risk table: Name | Stage | Drop Risk Score (color bar) | Top Signal | Action

- Drop Risk Score shown as a horizontal mini bar (0-100) with color gradient (green→amber→red)

- Top Signal: shows the single biggest contributor to risk ('3 negative sentiments' / 'No reply 8 days' / 'Low readiness 28%')

- Action column: 'View' link (→ MESSAGES tab) and 'Add to Queue' button (adds to HRMS-0462 if not already there)

- Bottom — Sentiment Trend chart: 14-day line chart showing % positive vs % negative messages per day

- Bottom right — Stage Risk Breakdown: horizontal bar chart showing average risk score per pipeline stage

## Step 3: Build dashboard filters

- Filter by Risk Level: All / Critical / High / Medium

- Filter by Stage: All / Qualifying / Screened / Interview / Offer / Preboarding

- Filter by Risk Dimension: All / Low Response Rate / Negative Sentiment / Stuck in Stage / Low Readiness

- Filters apply to the candidates table instantly (client-side filter on loaded data — no new API call needed for simple filters)

## BR-01: Dashboard Only Shows Active Candidates

Exclude COMPLETED and WITHDRAWN candidates from all dashboard metrics. The risk dashboard is for actionable, live candidates only. Historical data is in analytics (EPIC-12).

↳ Triggered by field: conversation.status NOT IN ('COMPLETED','WITHDRAWN')
