## Why — Business Rationale

- How much of BlitzenX's recruiting work is done by Thunder vs human recruiters? Which recruiters are the highest performers? How has the human dependency ratio changed over time? HRMS-P612 tracks current human dependency. This analytics story shows the trend — and proves (or disproves) that WROS is achieving its core goal of reducing human dependency to below 20% by Month 6.

## What — Scope

- Build: (1) Human dependency trend over time (Month 1 through Month 6+). (2) Thunder action vs human action counts by category. (3) Per-recruiter performance metrics (placements, time-to-qualify, candidate satisfaction). (4) Thunder effectiveness metrics (response rate, qualification rate).

## Before — Prerequisites

- HRMS-1201 analytics. HRMS-P612 human_dependency_metrics historical data.

## Implementation Steps

## Step 1: Build GET /api/analytics/recruiter-productivity

- Auth: Admin, Director. Params: date_from, date_to.

- Returns: { human_dependency_trend: [{ month, human_dependency_pct }] (Month 1 onward), thunder_vs_human: { messages_thunder: N, messages_human: N, fields_thunder: N, fields_human: N, interviews_thunder_scheduled: N, interviews_human_scheduled: N }, by_recruiter: [{ name, placements: N, avg_time_to_qualify_days, candidates_managed: N }], thunder_effectiveness: { qualification_rate_pct, avg_conversations_to_qualify, avg_response_time_hours } }

## Step 2: Build Productivity Dashboard at /admin/analytics/productivity

- Row 1: Human dependency % trend — line chart Month 1 to now. Target 20% dashed line. Shows trajectory.

- Row 2: Thunder vs Human split — stacked bar by action category (messaging, scheduling, field collection).

- Row 3: Per-recruiter performance table — placements, candidates managed, time to qualify.

- Row 4: Thunder effectiveness — qualification rate, avg conversations to qualify.
