## 2. WHY THIS EXISTS

Every AI action Thunder takes — a message sent, a field updated, a state changed, an override decision — must be permanently auditable. If a candidate complains they were contacted without consent, if a compliance audit is requested, if a decision needs to be reviewed: the audit log is the single source of truth. Without it, there is no accountability for AI actions.

This story formalizes the audit log as a first-class immutable record — separate from the conversation_events table which is operational, not audit-grade.

## 3. WHAT YOU ARE BUILDING

Build: (1) conversation_audit_log table — immutable, tamper-evident records of every significant action. (2) AuditLogger service that writes to it. (3) Query endpoint for compliance review. (4) Wire to all existing Thunder actions.

## 5. STEP-BY-STEP EXECUTION

▶  Follow these steps in exact order. If a step is unclear, ask the lead BA — never assume.

## Step 1: Create conversation_audit_log table

- CREATE TABLE conversation_audit_log: id UUID PK, tenant_id UUID NOT NULL, candidate_id UUID NOT NULL, conversation_id UUID nullable, audit_event_type VARCHAR(100) NOT NULL, audit_event_description TEXT NOT NULL, actor_type ENUM('AI','RECRUITER','HR','SYSTEM','CANDIDATE') NOT NULL, actor_id VARCHAR(200) NOT NULL (Thunder agent name OR user_id), before_state JSONB nullable (relevant state before action), after_state JSONB nullable (relevant state after action), ip_address VARCHAR(50) nullable, created_at TIMESTAMP NOT NULL default NOW()

- CRITICAL: No UPDATE or DELETE ever allowed on this table. INSERT ONLY. Enforce via: (1) DB role with INSERT only permission, (2) application-level check that no code updates or deletes audit records.

- Index on (tenant_id, candidate_id, created_at DESC) for queries

## Step 2: Build AuditLogger service

- AuditLogger.log({ tenant_id, candidate_id, conversation_id, audit_event_type, description, actor_type, actor_id, before_state, after_state })

- This is a simple INSERT function — no business logic, no transformations, no side effects

- Must be called synchronously within the same transaction as the action being audited

- Never fail silently: if INSERT fails, throw error and log to system error log. An action that cannot be audited should not proceed.

## Step 3: Wire AuditLogger to all key actions

- Conversation state transitions (HRMS-0418): log state before + after

- Override approvals (HRMS-P604): log approver, justification, outcome

- Ownership changes (HRMS-0410): log from owner, to owner

- Offer releases and decisions (HRMS-0454, 0456): log HR user who released, candidate decision

- Escalations (HRMS-0435): log trigger reason and escalating agent

- Manual recruiter messages (HRMS-0409): log recruiter_id and channel

- Candidate data corrections by recruiter (HRMS-0423): log old value, new value

## Step 4: Build audit query endpoint

- GET /api/candidates/{id}/audit-log — Auth: HR or ADMIN role only. Recruiter: HTTP 403.

- Returns all conversation_audit_log records for this candidate ordered by created_at ASC

- Response: { audit_entries: [{id, audit_event_type, description, actor_type, actor_id, before_state, after_state, created_at}], total_count }

- GET /api/admin/audit-log — Global audit log for entire tenant. ADMIN role only. Filter by date range, actor_type, event_type.

## 6B. BUSINESS RULES

▶  Every rule is non-negotiable. If in doubt, escalate to lead BA — never silently skip a rule.

## BR-01: Audit Log Is Immutable — Insert Only

No UPDATE, DELETE, or TRUNCATE ever permitted on conversation_audit_log. Enforced at DB level (INSERT-only role) and application level. Any attempt to modify audit records must throw an error and be logged as a security incident.

↳ Triggered by field: INSERT ONLY — enforced at DB and application levels

## BR-02: AuditLogger Failure Blocks the Action

If AuditLogger.log() fails (DB error, timeout): the originating action must also fail. We will not allow Thunder to take actions that cannot be audited. This is a hard requirement.

↳ Triggered by field: Audit write failure = action failure
