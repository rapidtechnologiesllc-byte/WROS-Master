## Why — Business Rationale

- When a BU Head clicks on an employee in the BU Dashboard, they need the full picture: every KPI, every week, the trajectory chart, escalation history, peer survey results, certification clock status, and the LLM-generated narrative. This is not a summary card — it is the complete record of this employee's journey at BlitzenX, from Day 1 of Buddy Program to their current status.

## What — Scope

- Build the individual employee scorecard detail page: full 35-KPI history with weekly trends, certification clock timeline, performance event feed, LLM narrative, escalation history, peer survey scores, and milestone status. Exportable to PDF.

## Before — Prerequisites

- HRMS-0520 buddy KPI data. HRMS-0515 performance store. HRMS-0522 clock. HRMS-0524 peer surveys.

## Implementation Steps

## Step 1: Build employee scorecard detail API

- GET /api/employees/{id}/scorecard: Auth BU Head, RM, HR. Returns: { employee_info, buddy_program { score_by_week, kpi_breakdown[35], graduation_decision }, certification_clock { status, billable_days, resets, reset_history }, performance_summary { lm_narrative, trajectory, strengths[], concerns[] }, weekly_manager_scores { by_week: [{ week, accountability, requirements, development, velocity, client_feedback }] }, peer_surveys { week6: { score, themes[] }, week12: { score, themes[] } }, escalations [{ date, type, classification, clock_impact }], milestones [{ title, type, status, target_date, completed_date }] }

## Step 2: Build scorecard UI

- Route: /admin/employees/{id}/scorecard. Accessible from BU Dashboard row click.

- Tab 1 — Overview: LLM narrative card, certification clock widget, status badges.

- Tab 2 — Buddy Program: 35-KPI radar chart (4-week view), category score cards, trajectory chart Week 1 vs Week 4.

- Tab 3 — Specialty Performance: weekly manager score charts per dimension, peer survey results, escalation timeline.

- Tab 4 — Milestones: all milestones by type with completion history.

- Tab 5 — History: full chronological event feed from performance store.

## Business Rules

## BR: Scorecard Is Read-Only — No Editing

- Every data point on the employee scorecard comes from source systems. Nothing can be edited from this page. If data is wrong: fix the source (manager bot, buddy form, timesheet). The scorecard is a consolidated view only.

- Field: All fields read-only. Source system is the single truth.
