## 2. WHY THIS EXISTS

BlitzenX's HARD RULE #5: If a candidate passes L1 but fails L2, they are automatically rejected — they cannot proceed to offer without explicit BU Head reversal. This was implemented partially in HRMS-P206 (L1 FAIL auto-cancels L2). This story handles the inverse case: L1 PASS + L2 FAIL = auto-reject, with BU Head as the only role who can reverse it.

## 3. WHAT YOU ARE BUILDING

Build: (1) Auto-reject trigger when L2 outcome=FAIL after L1 outcome=PASS. (2) BU Head reversal workflow. (3) Candidate notification on auto-reject. (4) Audit logging.

## 5. STEP-BY-STEP EXECUTION

▶  Follow these steps in exact order. If a step is unclear, ask the lead BA — never assume.

## Step 1: Build auto-reject trigger on L2 FAIL after L1 PASS

- Listen for interview.feedback_submitted event from HRMS-P206

- If event.outcome=FAIL AND interview_type=L2: check if L1 for same candidate+job has outcome=PASS

- If yes: AUTO-REJECT. INSERT hiring_decisions: { decision='REJECT', justification='Auto-rejected: L1 PASS, L2 FAIL per BlitzenX hiring policy.', decided_by='SYSTEM' }

- Call transitionState() to COMPLETED with reason='AUTO_REJECTED_L2_FAIL'

- Thunder sends empathetic rejection message to candidate (same template as HRMS-P207 manual rejection)

- Publish event: hiring.auto_rejected { candidate_id, job_id, reason: 'L1_PASS_L2_FAIL' }

## Step 2: Build BU Head reversal capability

- BU Head sees auto-rejected candidates in HRMS-P208 oversight view with special tag: 'AUTO-REJECTED (L1 Pass/L2 Fail)'

- 'Reverse Auto-Rejection' button (same pattern as HRMS-P208 Override): requires 150-char justification.

- On reversal: UPDATE hiring_decisions to indicate reversed. Candidate conversation state reopened to QUALIFIED (eligible for offer readiness check again).

- Log: HIRING_AUTO_REJECTION_REVERSED in conversation_audit_log

- Notify L2 interviewer: 'Your FAIL assessment for [Candidate] was reversed by BU Head [Name]. Reason: [justification].'

## 6B. BUSINESS RULES

▶  Every rule is non-negotiable. If in doubt, escalate to lead BA — never silently skip a rule.

## BR-01: Only BU Head Can Reverse — Not HM, Not Director

This is specifically a BU Head authority, separate from the Director+BU Head dual approval for experience override. A single BU Head approval is sufficient to reverse an L1-PASS-L2-FAIL auto-rejection. This reflects that BU Head has direct oversight of technical hiring quality.

↳ Triggered by field: BU Head sole authority for this specific reversal

## BR-02: Auto-Reject Fires Immediately on L2 FAIL Submission

The auto-reject check runs the instant interview_feedback with outcome=FAIL is submitted for L2 (where L1 was PASS). No delay, no batch job. The candidate and recruiting team are notified within the same transaction as the feedback submission.

↳ Triggered by field: Immediate trigger — synchronous with feedback submission
