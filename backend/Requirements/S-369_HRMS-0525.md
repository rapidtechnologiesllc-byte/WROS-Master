## Why — Business Rationale

- The Core Certification scorecard is the artifact the BU Head and RM use to make the most important talent decision in BlitzenX. It must consolidate every signal — 35 Buddy KPIs, 16+ weeks of manager reports, peer trust scores, milestone history, escalation record, timesheet discipline, interview quality — into a single coherent picture. The BU Head should be able to read this scorecard in 5 minutes and have genuine confidence in the decision they make.

## What — Scope

- Build the Core Certification Scorecard: auto-generated PDF and interactive screen view consolidating all performance signals into a structured, readable assessment with AI narrative, visual score breakdown, risk flags, and decision fields for RM and BU Head.

## Before — Prerequisites

- HRMS-0518 AI assessment complete. All HRMS-0515 performance events from Buddy Program through 90-day certification. HRMS-0513 review record created.

## Implementation Steps

## Step 1: Build scorecard data aggregation service

- ScorecardBuilder.build(employee_id, review_id): aggregates from all sources — buddy_kpi_scores (35 KPIs, weighted), manager_weekly averages (per category), peer_trust_score (Week 6 + 12 weighted), milestone_completion_rate, escalation_record (type + clock_reset_count), timesheet_discipline_pct, interview_quality_score.

- Maps to structured scorecard_data: { employee_info, clock_summary { billable_days, reset_count, certified_date }, buddy_summary { overall_score, top_3_strengths, top_3_concerns }, specialty_summary { manager_avg, peer_trust, escalations, timesheet_pct, milestone_rate }, ai_assessment { recommendation, confidence, evidence_summary, risk_flags }, scoring_breakdown: { category: score }[] }

## Step 2: Build interactive scorecard UI

- Route: /admin/core-eligibility/{review_id}/scorecard

- Section 1: Employee header — name, engine, start date, Buddy graduation date, certification date.

- Section 2: Score breakdown radar chart — 8 categories, scored 0-100, target threshold line at 65.

- Section 3: AI Assessment panel — recommendation badge, confidence %, evidence summary, risk flags.

- Section 4: Buddy Program summary — weighted score, top strengths, top concerns from KPI data.

- Section 5: Specialty Deployment summary — manager averages, peer trust, escalation record, timesheet %.

- Section 6: Decision fields — RM Recommendation (dropdown + notes). BU Head Decision (dropdown + notes). Both required.

## Step 3: Build PDF export

- [Export Scorecard PDF] generates formatted PDF suitable for HR records. Includes all sections + decision fields once complete. Stored in S3 as permanent record attached to core_eligibility_reviews.

## Business Rules

## BR: Scorecard Is Read-Only — AI and Data Cannot Be Edited

- The scorecard displays calculated data from source systems. No field on the scorecard can be edited. If data is incorrect: fix the source system record. The scorecard is a read-and-decide artifact, not an edit artifact.

- Field: All scorecard fields read-only. Decision fields only editable fields.

## BR: PDF Stored Permanently — Never Deleted

- Exported scorecard PDFs are stored in S3 with immutable naming: {employee_id}_{review_id}_{date}.pdf. They are never deleted. This is the legal record of the Core Certification decision.

- Field: Immutable S3 storage — never deleted
