## Why — Business Rationale

- Not all staffing demand comes from planned demand cycles. Clients call with urgent needs — a project starts Monday, their consultant just resigned, they won a new contract yesterday. Adhoc demand is the rapid-response track: faster intake, faster bench check, faster submission. Without a dedicated adhoc flow, urgent requests get lost in the standard queue.

## What — Scope

- Build the adhoc demand creation flow: quick intake form, client-linked, urgency-classified, immediately routed to bench check and AI classification. Distinct from planned demand — no approval workflow, immediate execution.

## Before — Prerequisites

- HRMS-0103 demands table. HRMS-0102 clients.

## Implementation Steps

## Step 1: Add adhoc demand fields to demands table

- ALTER TABLE demands ADD COLUMN demand_type ENUM('PLANNED','ADHOC') default 'PLANNED'.

- ALTER TABLE demands ADD COLUMN adhoc_reason ENUM('CLIENT_URGENT','CONSULTANT_RESIGNED','NEW_CONTRACT','BACKFILL','OTHER') nullable.

- ALTER TABLE demands ADD COLUMN adhoc_received_via ENUM('PHONE','EMAIL','PORTAL','WHATSAPP') nullable.

- ALTER TABLE demands ADD COLUMN adhoc_sla_hours INTEGER nullable.

## Step 2: Build adhoc demand intake API

- POST /api/demands/adhoc: { client_id, job_title, required_skills, min_experience_years (default 5), delivery_engine, adhoc_reason, adhoc_received_via, required_by_date, notes }. Creates demand with demand_type=ADHOC, status=OPEN, urgency=IMMEDIATE.

- Auth: RM, CS, Admin.

- Route: /admin/demands/adhoc/new — quick form optimized for speed.

## Step 3: Build adhoc demand queue

- Separate 'Adhoc Queue' section in RM Dashboard — always visible at top. Real-time badge: 'N Adhoc Demands Open'. SLA breach alert when adhoc older than adhoc_sla_hours.

## Business Rules

## BR: Adhoc Demands Are Always IMMEDIATE Urgency

- All adhoc demands are created with urgency=IMMEDIATE. Not user-selectable.

- Field: urgency=IMMEDIATE — system-set

## BR: Bench-First Still Required — 2-Hour Check SLA

- BenchFirstPolicyEngine.check() must run before external sourcing even for adhoc. SLA compressed to 2 hours.

- Field: 2-hour bench check SLA for adhoc
