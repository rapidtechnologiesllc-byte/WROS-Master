## Why — Business Rationale

- Email is the single biggest reason a recruiter or RM leaves WROS mid-task today — a client update, a candidate reply, a calendar conflict, all live in Outlook, forcing a context switch away from whatever WROS screen they were working. Embedding the actual Outlook interface (not rebuilding a worse imitation of it) closes that gap without asking anyone to learn a new email client.

## What — Scope

- Outlook Mail and Calendar rendered as a tab inside the WROS shell (per S-379's framework), using the real Outlook web interface via Graph API embedding — full read/send/schedule functionality, not a read-only preview.

## Before — Prerequisites

- S-379 must be live — this is the first real tenant of its tab framework.

## Implementation Steps

## Step 1: Embed the Outlook Mail view

- Render Outlook Web Access (or the equivalent embeddable Graph-backed mail component) inside the S-379 tab framework.

- Full functionality: read, reply, compose, search — this is the real Outlook interface, not a simplified WROS-built substitute.

## Step 2: Embed the Outlook Calendar view

- Same embedding approach for Calendar — this is also where HRMS-1306's existing interview scheduling integration (already used by S-164/S-248/S-240 per Section 11) becomes visually unified with the user's actual calendar view instead of being a separate scheduling widget.

## Step 3: Build the WROS-context linking

- When a WROS screen (e.g., a candidate profile) has an associated email thread or scheduled interview, a direct link opens that specific item in the embedded tab rather than requiring the user to search for it manually.

## Business Rules

BR: BR-1402-01 — This embeds the real Outlook interface, WROS does not reimplement email/calendar logic

- Matches the explicit architectural direction — WROS is the shell and the point of entry, Microsoft's own product handles the actual email/calendar functionality, so BlitzenX gets Microsoft's ongoing feature development for free rather than maintaining a competing implementation.

- Field: No email-sending, message-storage, or calendar-event logic exists in WROS's own database for this story — it is purely an embedding/deep-linking layer
