## Notable corrections to the sheet

1. **S-102 (marked "Done")** is actually read-only — the Hiring Manager Decision View has no Approve/Reject/Hold controls, no panel-split flags, no AI recommendation, and no salary-vs-budget comparison. Approval happens through a disconnected action elsewhere, so the spec's "must view all feedback before approving" gate does not exist in any form.
2. **S-105 (marked "Done")** is mostly real (backend + bell dropdown + mark-read all genuine) but is missing the "click to deep-link" behavior entirely — clicking a notification does nothing but offer a manual mark-read button.
3. **S-081** (Universal Identity Engine) has real, tested dedup logic, but it *refuses* duplicates rather than *merging* them as the story requires — a meaningful behavioral gap, not just a missing UI, since no merge event is ever logged for S-092's audit dashboard to show.
4. **EPIC-P3 is effectively 0% real** despite some adjacent infrastructure (S-347/348/349 Desire Intelligence Engine, S-045 reactivation campaign) that a shallow keyword search might mistake for coverage — none of the 9 stories' specific mechanisms (career check-ins, CRS formula, quarterly nurture, market-signal triggers, campaign config UI) exist.
5. **S-085 candidate portal home dashboard** is missing its offer-status card entirely, consistent with the fact that no offer viewer (S-089) was ever built.
