# Complete Organization Hierarchy (17 Levels)

## Hierarchy Levels (hierarchy_level in OrgNode)

The organization has **17 hierarchy levels** plus specialization:

```
Level 17: CEO (C-Level)
Level 16: Partner / C-Level (CFO, CWP, etc.)
Level 15: Senior Vice President (SVP)
Level 14: Vice President (VP)
Level 13: Assistant Vice President (AVP)
Level 12: Senior Director
Level 11: Director
Level 10: Assistant Director
Level 9:  Senior Manager
Level 8:  Manager
Level 7:  Associate Manager
Level 6:  Lead Consultant
Level 5:  Senior Consultant
Level 4:  Consultant
Level 3:  Senior Associate
Level 2:  Associate
Level 1:  Intern
```

## Specializations (specialization in OrgNode)

Each person at ANY hierarchy level can have a **specialization** that defines their daily work:

### Recruitment Specialization
- Recruiter (finds candidates)
- Sourcer (research & outreach)
- Coordinator (process management)
- Manager (recruitment team lead)

### HR Specialization
- HR Administrator
- Compliance Officer
- Compensation Specialist
- Employee Relations Manager

### Delivery Specialization
- Development (Software Engineer, Architect)
- Business Analysis (BA, Solution Architect)
- Quality Assurance (QA, Test Engineer)
- Project Management (PM, Scrum Master)

### Finance Specialization
- Accountant
- Analyst
- Controller
- Finance Manager

### Sales/Account Management Specialization
- Account Executive
- Account Manager
- Account Coordinator
- Sales Director

## The Two-Dimensional System

**Every person is defined by:**

### Dimension 1: Hierarchy Level (1-17)
**Defines:** Authority, decision-making power, reporting structure
- **Level 1-3:** Individual Contributors (Interns, Associates, Senior Associates)
- **Level 4-6:** Specialists (Consultants, Lead Consultants)
- **Level 7-10:** Management (Managers, Directors)
- **Level 11-14:** Senior Leadership (Senior Directors, VPs)
- **Level 15-16:** Executive (SVP, C-Level Partners)
- **Level 17:** CEO

### Dimension 2: Specialization
**Defines:** What they do day-to-day, their expertise area, their team
- Recruitment, HR, Development, Business Analysis, QA, Project Management, etc.

## Specialization Teams

### Recruitment Team
- Levels 1-6: Sourcer → Consultant → Senior Consultant → Lead Consultant
- Levels 7-10: Associate Manager → Manager → Senior Manager → Director
- Levels 11+: Senior Director → VP → SVP → Partner (HR/Recruitment)
- Reports through recruitment specialization chain

### Development Team
- Levels 1-6: Junior Dev → Developer → Senior Developer → Lead Engineer
- Levels 7-10: Associate Manager → Manager → Senior Manager → Director
- Levels 11+: Senior Director → VP Engineering → SVP → Partner (Engineering)
- Reports through development specialization chain

### Delivery/Project Management Team
- Levels 1-6: Coordinator → PM → Senior PM → Lead PM
- Levels 7-10: Associate Manager → Manager → Senior Manager → Director
- Levels 11+: Senior Director → VP → SVP → Partner (Delivery)
- Reports through delivery specialization chain

### Finance Team
- Levels 1-6: Accountant → Analyst → Senior Analyst → Lead Accountant
- Levels 7-10: Finance Manager → Senior Manager → Director → Senior Director
- Levels 11-14: AVP Finance → VP Finance → SVP Finance
- Level 16: CFO (C-Level Partner)
- Level 17: CEO (final authority on financials)

### HR/Compliance Team
- Levels 1-6: HR Coordinator → Administrator → Specialist → Manager
- Levels 7-10: Senior Manager → Manager → Senior Manager → Director
- Levels 11-14: Senior Director → AVP HR → VP HR → SVP HR
- Level 16: CWP (Chief Workforce Operations) - C-Level Partner
- Level 17: CEO (final authority on people)

## Key Rules for Hierarchy Enforcement

1. **Cannot skip more than 2 levels** when reporting (Intern → Associate/Senior Associate OK, but not Intern → Consultant)
2. **Specializations stay within domain** (Dev can report to Dev leads/managers, not Recruitment)
3. **Interns (Level 1) cannot be managers** of anyone
4. **Managers (Level 7+) must have direct reports** (empty teams indicate organizational problems)
5. **Specialization changes require new role** (can't just change specialization without hierarchy approval)

## Escalation Chains by Specialization

### Recruitment Escalation
```
Intern → Associate → Senior Associate → Consultant → Senior Consultant 
→ Lead Consultant → Associate Manager → Manager → Senior Manager 
→ Director → Senior Director → AVP HR → VP HR → SVP HR → CWP → CEO
```

### Development Escalation
```
Junior Dev → Developer → Senior Dev → Lead Engineer → Associate Manager 
→ Manager → Senior Manager → Director → Senior Director 
→ AVP Engineering → VP Engineering → SVP Engineering → CTO/Partner → CEO
```

### Delivery/Project Management Escalation
```
Coordinator → PM → Senior PM → Lead PM → Associate Manager 
→ Manager → Senior Manager → Director → Senior Director 
→ AVP Delivery → VP Delivery → SVP Delivery → Partner (Delivery) → CEO
```

### Finance Escalation
```
Accountant → Analyst → Senior Analyst → Lead Accountant → Manager 
→ Senior Manager → Director → Senior Director → AVP Finance 
→ VP Finance → SVP Finance → CFO → CEO
```

## OrgNode Schema Updates

```python
class OrgNode(Base):
    # Existing fields
    id: UUID
    user_id: UUID FK → Users.UserID
    name: str
    node_type: str  # PERSON, ROLE, DEPARTMENT
    parent_node_id: UUID FK → OrgNode.id
    business_unit_id: UUID FK
    
    # Hierarchy - now 17 levels
    hierarchy_level: int  # 1-17
    
    # Authority (derived from hierarchy_level + specialization)
    authority_level: str  # INDIVIDUAL, TEAM, DEPARTMENT, DIVISION, EXECUTIVE, BOARD
    
    # Decision domains
    decision_domains: str  # CSV: HIRING, BUDGET, PRICING, TIMELINE, SCOPE, POLICY
    
    # NEW: Specialization (what they do day-to-day)
    specialization: str  # Recruitment, Development, QA, HR, Finance, etc.
    specialization_domain: str  # Optional: Sub-specialization
    
    # Contact & timestamps
    email: str
    created_at: datetime
    updated_at: datetime
```
