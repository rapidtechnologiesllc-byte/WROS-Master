# BERT Resume Parser Fine-Tuning Guide

## Overview

Transform resume parsing from pattern-matching (SLM) to machine learning (BERT) for 10-25% accuracy improvement.

**Accuracy Evolution:**
- **Baseline (SLM):** 70% (pattern-based extraction)
- **Target (BERT):** 92%+ (ML-based with fine-tuning)
- **Improvement:** +22% absolute improvement

## The Three-Stage Pipeline

### Stage 1: Collect Real Training Data (50-100 examples)

**What:** Extract and validate resume data from real resumes

**Input:** Resumes from OneDrive folder (PDF/DOCX files)

**Process:**
```bash
python backend/scripts/collect_training_data.py \
  --resume-dir "/path/to/resumes" \
  --output backend/training_data.json
```

**What happens:**
1. Script finds all PDF/DOCX files in folder
2. Extracts text from each resume
3. Parses with current SLM
4. Shows you parsed data: name, title, skills, etc.
5. You validate/correct (interactive)
6. Saves validated examples to JSON

**Expected output:** `training_data.json` with 50-100 validated examples

**Example interaction:**
```
[1/87] Processing: john_smith_resume.pdf
  → Extracting text... ✓ (2847 chars)
  → Parsing with SLM... ✓

  📋 Review extraction results:
     Name: John Smith
     Title: Senior Software Engineer
     Employer: Google
     Skills: 8 found
     Jobs: 4 found
     Education: 1 found

     Accept? (y/n/edit): y  ← you type this

  ✅ Added to training set (47 total)
```

**Time commitment:** ~1-2 hours (5 min per resume × 100)

---

### Stage 2: Generate Synthetic Training Data (5000+ examples)

**What:** Use Claude to generate realistic variations of your real examples

**Why:** 
- Real data alone: 50-100 examples (not enough for good BERT training)
- Adding synthetic: 5000-5100 examples (sufficient for fine-tuning)
- Cost: One-time Claude API calls (~$5-10)
- Result: 50x training data expansion

**Input:** `training_data.json` (50-100 real examples)

**Process:**
```bash
python backend/scripts/generate_synthetic_examples.py \
  --input backend/training_data.json \
  --output backend/synthetic_data.json \
  --count 5000
```

**What happens:**
1. For each real example:
   - Extract structure (name, title, skills, etc.)
   - Call Claude API with example
   - Claude generates 50 realistic variations
   - Each variation has different name, company, skills, dates
2. Accumulate until reaching 5000+ examples
3. Validate synthetic data quality
4. Save to JSON

**Example generation:**
```
Real example:
{
  "full_name": "Sarah Johnson",
  "current_title": "Product Manager",
  "current_employer": "Microsoft",
  "skills": ["Product Strategy", "Python", "AWS"],
  "work_history": [...]
}

Synthetic variations generated by Claude:
- Michael Chen, Product Manager, Apple, [AWS, Kubernetes, Go]
- Maria Garcia, Senior PM, Amazon, [Python, Agile, Leadership]
- Alex Kumar, PM II, Google, [AWS, React, SQL]
- ... (50 more variations)
```

**Expected output:** `synthetic_data.json` with 5000+ examples

**Time:** ~15-30 minutes (depends on API response times)

**Cost:** ~$5-10 (Claude API calls)

---

### Stage 3: Fine-Tune BERT Model

**What:** Train a BERT model on your combined dataset

**Input:** 
- `training_data.json` (50-100 real examples)
- `synthetic_data.json` (5000+ synthetic examples)

**Process:**
```bash
python backend/scripts/fine_tune_bert.py \
  --training-data backend/training_data.json \
  --synthetic-data backend/synthetic_data.json \
  --output backend/models/resume_parser_bert \
  --epochs 3
```

**What happens:**
1. Load real + synthetic data (5000-5100 total)
2. Split into 80% training, 20% validation
3. Tokenize with BERT tokenizer
4. Fine-tune bert-base-uncased for 3 epochs
5. Evaluate on validation set
6. Save trained model

**Expected output:** 
- `models/resume_parser_bert/pytorch_model.bin` (trained model)
- `models/resume_parser_bert/config.json` (configuration)
- `models/resume_parser_bert/tokenizer.json` (tokenizer)

**Performance expectations:**
- Validation accuracy: 92-95% (on test set)
- Inference speed: 100-500ms per resume
- Requires GPU (optional, works on CPU but slower)

**Time:** 
- CPU: 1-2 hours
- GPU: 15-30 minutes

**Hardware:**
- GPU recommended (NVIDIA, Apple Silicon, or cloud)
- CPU works but slower

## Troubleshooting

### Issue: "Missing dependencies" on fine_tune_bert.py

**Fix:**
```bash
pip install transformers torch datasets scikit-learn
```

### Issue: Out of memory when training

**Solution 1 (reduce batch size):**
```bash
python fine_tune_bert.py --epochs 1 --batch-size 8
```

**Solution 2 (use smaller model):**
```bash
python fine_tune_bert.py --model distilbert-base-uncased
```

**Solution 3 (use cloud GPU):**
- Google Colab: https://colab.research.google.com
- AWS SageMaker
- Paperspace Gradient

### Issue: Claude API rate limits

**Fix:**
```bash
# Add delay between generations
python generate_synthetic_examples.py --input training_data.json --delay 2
```
